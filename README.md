# MLB POSTSEASON PREDICTION 2026

5人専用のMLBポストシーズン予想ゲーム。

## 構成
- Frontend: GitHub Pages
- API / DB: Supabase
- 追加費用: 0円構成

## 主な機能
- PLAYER 1〜5 / ADMIN の4桁PINログイン
- GAME予想（スコア、1〜10P、BOOST）
- SERIES予想（勝者、シリーズスコア、UPSET）
- 大会前予想
- 自動採点・ランキング
- ラウンド最低使用P / 自由ポイント管理
- 管理者による結果確定、PIN・名前変更、後続ラウンド登録

## 公開
GitHub Pages + GitHub Actions で main ブランチを自動公開する。
